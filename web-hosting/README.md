# Web hosting

Guides for GitHub Actions that publish to an ordinary web host, a server
where you have an account and a folder that becomes your website.

New to GitHub Actions? Do [First workflow](../basics/first-workflow/) first.

## Reading order

| Guide | What you do |
|---|---|
| [Deploy with rsync over SSH](deploy-with-rsync-over-ssh/) | Push to `main`, and the folder `public/` is copied to the web host with rsync. Uses [Secrets and variables](../basics/secrets-and-variables/). |
